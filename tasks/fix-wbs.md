# WBS: fix

- [ ] Phase 1: Reproduce and Diagnose the Bug
Reproduce the issue locally or via logs to confirm the exact failure mode. Identify the root cause with evidence (logs, error messages, failing tests). Document findings in `tasks/todo.md` with a clear problem statement.
- [ ] Phase 2: Implement the Fix
Apply the minimal code change(s) to address the root cause. Update only the necessary source files. Do not touch tests, docs, or configs unless they are part of the bug.
- [ ] Phase 3: Verify the Fix
Run the relevant tests and/or manual verification steps to confirm the bug is resolved. Check that no regressions were introduced. Mark the task complete in `tasks/todo.md` and update `tasks/lessons.md` with any new patterns learned.
